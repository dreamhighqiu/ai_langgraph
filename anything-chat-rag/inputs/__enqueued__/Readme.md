**文件说明**

1.  /trainData：存储训练数据，主要用于训练模型以及对测试数据的归一化处理。

    /model：存储情绪指数模型。

    /code：存储情绪指数算法代码。

    以上三个文件夹很重要，其中前两个不用做任何修改，直接 copy 就行。

    /情绪手表数据：情绪手表小程序上的情绪指数数据，此数据主要用于与自研算法结果进行对比。

2.  /code 下面有三个代码，(1) train_model.py 是我用于训练模型的代码，无需关注。(2) 运行 parse_txt.py 即可解析 txt 文件并且它会调用 predict_model.py 去预测得到其情绪指数值。parse_txt.py 代码可以根据 api 接口需要进行修改。(3) predict_model.py 代码中有一个参数 a（第 32 行，目前设置为 300）是可以根据我们的 RR 数据量以及模型性能进行调整的，一般可以设置为 300-500，但如果 RR 数量较少，也可以考虑参数 a 调整为 100-200（模型效果可能有些影响），依实际情况而定。

3.  关于 predict_model.py 的返回值 affect 字段，其对应关系为{'欣然':1, '平静':2, '安宁':3, '松懈':4}。

4.  近期，我也通过同时佩戴和顺成手表和第三方情绪手表，采集了一些数据，并且用我们自研的情绪算法计算其情绪指数值，然后与第三方情绪手表的结果进行对比，详细分析结果请查阅"情绪手表算法与自研算法结果对比.xlsx"。

5.  由于在使用和顺成手表采集数据时，遇到了不少的问题，因此我根据收集的信息，写了一份手表使用注意事项文档，可查阅 “和顺成手表使用注意事项.txt”，仅供内部使用参考。
