### 1.2 前后端字段名称不匹配

**后端返回字段（驼峰命名）：**
```python
class ProjectModel(BaseModel):
    project_id: Optional[int]
    project_name: str
    project_type: str
    description: Optional[str]
    create_time: Optional[datetime]
    status: Optional[str]
    remark: Optional[str]
```

**前端期望字段：**
- 前端需要统一使用驼峰命名（camelCase）
- 后端已使用下划线命名（snake_case）

**解决方案：**
- ✅ 前端已统一修改为驼峰命名,匹配后端返回
- 后端保持下划线命名,通过 Pydantic 自动转换

## 四、技术架构说明

### 4.1 数据流向

```
前端 -> 后端API -> Service层 -> Agent服务(testing-agents-service) -> K6执行
  ↑                                                                          ↓
  └────────────────── SSE实时日志 ←──────────────────────────────────────────┘
```

### 4.2 关键技术点

1. **SSE流式传输**：用于实时推送K6执行日志
2. **MinIO对象存储**：存储脚本文件和测试报告
3. **LangGraph Agent**：AI生成K6脚本
4. **RAG知识库**：增强脚本生成质量
