## 七、常见问题FAQ

### Q1: 菜单中看不到"项目管理"？
**A**: 检查以下几点：
1. 确保路由配置已更新（permission.js）
2. 清除浏览器缓存并重新登录
3. 检查用户是否有 `testing:project:list` 权限

### Q2: 项目列表加载失败？
**A**: 检查：
1. 后端服务是否正常启动
2. 数据库连接是否正常
3. 浏览器控制台的错误信息
4. 后端日志的错误信息

### Q3: AI生成脚本失败？
**A**: 检查：
1. testing-agents-service 是否启动
2. gRPC连接是否正常
3. LangGraph配置是否正确
4. Agent是否有足够的上下文信息

### Q4: K6执行失败？
**A**: 检查：
1. K6是否正确安装
2. K6脚本语法是否正确
3. 测试目标是否可访问
4. 系统资源是否充足
