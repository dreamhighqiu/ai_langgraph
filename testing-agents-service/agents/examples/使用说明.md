# 测试用例生成智能体 - 使用说明

## 📋 概述

本智能体能够根据需求文档、用户故事或功能描述，自动生成高质量的测试用例。

## ✨ 核心特性

### 1. 自动使用上下文参数

智能体会自动使用前端传入的参数，无需用户手动提供：

- ✅ **项目标识符** - 自动从上下文获取
- ✅ **文件夹 ID** - 自动从上下文获取  
- ✅ **模板类型** - 自动选择（普通/BDD）

### 2. 支持两种测试用例格式

- **普通测试用例** (`test_case`)：传统的步骤式测试用例
- **BDD 测试用例** (`test_case_bdd`)：行为驱动开发格式

### 3. 智能测试设计

- 自动识别测试场景（正常流程、异常流程、边界条件）
- 合理设置优先级和测试类型
- 添加有意义的标签

## 🚀 快速开始

### 步骤 1: 准备上下文

```python
from app.agents.testcase_generator import testcase_generator_agent, TestCaseGeneratorContext

# 创建上下文（通常由前端传入）
context = TestCaseGeneratorContext(
    project_identifier="PROJ-001",           # 项目标识符
    folder_id="your-folder-uuid",            # 文件夹 UUID
    template_type="test_case"                # 模板类型
)
```

### 步骤 2: 调用智能体

```python
# 用户输入
user_input = "为用户登录功能生成测试用例"

# 调用智能体
result = await testcase_generator_agent.ainvoke({
    "messages": [{"role": "user", "content": user_input}],
    "context": context
})

print(result)
```

## 💡 使用示例

### 示例 1: 生成登录测试用例

```python
context = TestCaseGeneratorContext(
    project_identifier="PROJ-001",
    folder_id="folder-uuid",
    template_type="test_case"
)

user_input = """
为用户登录功能生成测试用例。

功能要求：
- 用户名和密码登录
- 支持记住密码
- 登录失败3次锁定账号
"""

result = await testcase_generator_agent.ainvoke({
    "messages": [{"role": "user", "content": user_input}],
    "context": context
})
```

**智能体会自动：**
1. 使用 `project_identifier="PROJ-001"`
2. 使用 `folder_id="folder-uuid"`
3. 创建普通格式的测试用例
4. 覆盖正常流程、异常流程、边界条件

### 示例 2: 生成 BDD 测试用例

```python
context = TestCaseGeneratorContext(
    project_identifier="PROJ-002",
    folder_id="folder-uuid",
    template_type="test_case_bdd"  # 使用 BDD 模板
)

user_input = "为购物车添加商品功能生成测试用例"

result = await testcase_generator_agent.ainvoke({
    "messages": [{"role": "user", "content": user_input}],
    "context": context
})
```

**智能体会自动：**
1. 使用 BDD 格式（Given-When-Then）
2. 创建 Feature 和 Scenario
3. 添加合适的 Background

## 📝 上下文参数说明

### project_identifier（必填）

- **说明**: 项目标识符，如 "PROJ-001"
- **来源**: 前端传入
- **用途**: 指定测试用例所属项目

### folder_id（必填）

- **说明**: 文件夹 UUID
- **来源**: 前端传入
- **用途**: 指定测试用例存放位置

### template_type（可选）

- **说明**: 测试用例模板类型
- **可选值**: 
  - `test_case` - 普通测试用例（默认）
  - `test_case_bdd` - BDD 测试用例
- **来源**: 前端传入或使用默认值

## ⚠️ 重要提示

### 1. 参数自动使用

智能体会**自动使用**上下文中的参数，**不会**询问用户：

```
❌ 错误的对话：
智能体: "请提供项目标识符"
用户: "PROJ-001"

✅ 正确的对话：
用户: "为登录功能生成测试用例"
智能体: [直接使用上下文中的 PROJ-001 创建测试用例]
```

### 2. 参数验证

如果上下文参数为空，智能体会提示错误：

```python
context = TestCaseGeneratorContext(
    project_identifier="",  # 空值
    folder_id="",           # 空值
)

# 智能体会提示：
# "系统配置错误，缺少必要的项目或文件夹信息"
```

### 3. 模板选择

- 如果 `template_type="test_case"`，创建普通测试用例（使用 test_case_steps）
- 如果 `template_type="test_case_bdd"`，创建 BDD 测试用例（使用 feature/scenario）
- 用户可以在对话中要求使用特定模板
