# DeepAgents 核心概念速查卡 🚀

## 一句话总结

### SubAgent 的本质
**SubAgent 配置（字典） → `create_agent` → 真正的 Agent → 存储在闭包中 → 运行时调用**

### Backend 的本质
**统一接口（BackendProtocol） → 多种实现（State/Store/Sandbox/Composite） → 可插拔设计**

## SubAgent 核心要点

### 创建流程
```
1. 用户定义配置 (TypedDict)
   ↓
2. SubAgentMiddleware.__init__
   ↓
3. _get_subagents 函数
   ↓
4. create_agent(model, system_prompt, tools, middleware)  ← 🔥 关键
   ↓
5. CompiledStateGraph (真正的 Agent)
   ↓
6. 存储在 subagent_graphs 字典
   ↓
7. task 工具的闭包捕获
   ↓
8. 运行时: subagent.invoke(state)  ← 🔥 关键
```

### 关键代码位置
```python
# deepagents2/middleware/subagents.py

# 第 6 行: 导入 create_agent
from langchain.agents import create_agent

# 第 244 行: 创建通用子智能体
general_purpose_subagent = create_agent(
    default_model,
    system_prompt=DEFAULT_SUBAGENT_PROMPT,
    tools=default_tools,
    middleware=general_purpose_middleware,

# 第 270 行: 创建自定义子智能体
agents[agent_["name"]] = create_agent(

    system_prompt=agent_["system_prompt"],
    tools=_tools,
    middleware=_middleware,
)

# 第 348 行: 运行时调用
result = subagent.invoke(subagent_state)
```

## Backend 核心要点

### 接口定义
```python
# deepagents2/backends/protocol.py

class BackendProtocol(Protocol):
    def ls_info(self, path: str) -> list[FileInfo]: ...
    def read(self, file_path: str, offset: int = 0, limit: int = 2000) -> str: ...
    def write(self, file_path: str, content: str) -> WriteResult: ...
    def edit(self, file_path: str, old_string: str, new_string: str) -> EditResult: ...
    def grep_raw(self, pattern: str, path: str | None = None) -> list[GrepMatch]: ...
    def glob_info(self, pattern: str, path: str = "/") -> list[FileInfo]: ...
```

### files_update 字段
```python
# 返回 dict: 文件数据更新到 State
WriteResult(
    path="/test.txt",
    files_update={"/test.txt": {"content": [...], "modified_at": "..."}}
)
# → LangGraph 将 files_update 合并到 state["files"]
# → Checkpointer 自动持久化

# 返回 None: 文件已存储到外部
WriteResult(
    path="/test.txt",
    files_update=None
)
# → 文件已经存储到 Store/文件系统/数据库
# → 不需要更新 State
```

### 四种实现对比

| Backend | 存储位置 | files_update | 跨会话 | 执行命令 |
|---------|---------|--------------|--------|----------|
| StateBackend | Agent State | dict | ❌ | ❌ |
| StoreBackend | LangGraph Store | None | ✅ | ❌ |
| SandboxBackend | 沙箱环境 | None | ✅ | ✅ |
| CompositeBackend | 混合路由 | 取决于路由 | ✅ | ✅ |

## 快速配置模板

### 1. 基础配置（开发环境）
```python
from deepagents2 import create_deep_agent
from deepagents2.middleware.filesystem import FilesystemMiddleware
from deepagents2.backends.state import StateBackend
from langgraph.checkpoint.memory import MemorySaver

agent = create_deep_agent(
    model="openai:gpt-4o-mini",
    middleware=[
        FilesystemMiddleware(backend=lambda rt: StateBackend(rt))
    ],
    checkpointer=MemorySaver(),
)
```

### 2. 生产配置（持久存储）
```python
from deepagents2.backends.store import StoreBackend
from langgraph.store.memory import InMemoryStore

store = InMemoryStore()  # 生产环境用 PostgresStore

agent = create_deep_agent(
    model="openai:gpt-4o-mini",
    middleware=[
        FilesystemMiddleware(
            backend=lambda rt: StoreBackend(rt, namespace=("user-files",))
        )
    ],
    checkpointer=MemorySaver(),
    store=store,
)
```

### 3. 企业配置（SubAgent + CompositeBackend）
```python
from deepagents2.middleware.subagents import SubAgentMiddleware
from deepagents2.backends.composite import CompositeBackend

subagents = [
    {
        "name": "code-analyzer",
        "description": "代码分析专家",
        "system_prompt": "你是代码分析专家...",
        "tools": [],
    }
]

agent = create_deep_agent(
    model="openai:gpt-4o-mini",
    middleware=[
        FilesystemMiddleware(
            backend=CompositeBackend(
                default=lambda rt: StateBackend(rt),
                routes={
                    "/memories/": lambda rt: StoreBackend(rt, namespace=("memories",)),
                    "/projects/": lambda rt: StoreBackend(rt, namespace=("projects",)),
                }
            )
        ),
        SubAgentMiddleware(
            default_model="openai:gpt-4o-mini",
            subagents=subagents,
            general_purpose_agent=True,
        ),
    ],
    checkpointer=MemorySaver(),
    store=InMemoryStore(),
)
```

## 设计模式速查

### SubAgent 使用的模式
- **工厂模式**: `_get_subagents` 根据配置创建 Agent
- **策略模式**: 不同的 SubAgent 是不同的策略
- **闭包模式**: `task` 工具捕获 `subagent_graphs`

### Backend 使用的模式
- **策略模式**: `BackendProtocol` 定义接口，多种实现
- **适配器模式**: `FilesystemMiddleware` 适配不同 Backend
- **组合模式**: `CompositeBackend` 组合多个 Backend
- **工厂模式**: `BackendFactory` 创建 Backend 实例

## 常见问题速查

### Q: SubAgent 和普通函数有什么区别？
**A**: SubAgent 是完整的 Agent，可以多轮推理和调用工具；函数只能执行一次。

### Q: 什么时候用 StateBackend，什么时候用 StoreBackend？
**A**: 
- StateBackend: 临时文件、单会话、开发测试
- StoreBackend: 长期记忆、跨会话、用户偏好

### Q: files_update 返回 dict 和 None 有什么区别？
**A**:
- dict: 文件数据更新到 State，通过 Checkpointer 持久化
- None: 文件已存储到外部系统（Store/文件系统/数据库）

### Q: 如何自定义 Backend？
**A**: 实现 `BackendProtocol` 接口的所有方法即可。
